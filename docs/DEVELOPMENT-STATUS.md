## Prize logic

Prize funding would first pay for accessibility testing and compensated co-design,
then production hosting and security review, then further Obsidian/AT Protocol
integration. It would not fund clinical inference, autonomous ordering, location
surveillance, or unlicensed franchise content.

Official rules control the actual prize amounts, eligibility, tax treatment, and
submission obligations. Any award or in-kind support should be reviewed with a
qualified benefits counselor before acceptance.

## Rule-fit finding

File management does not inherently conflict with the hackathon. The submission is
stronger when file stewardship is framed as an Alexa+ MCP-enabled workflow with a
working, accessible experience—not as an unrelated storage utility. The prototype
must avoid uploading private vault contents, include only original or permitted
materials, disclose reused/open-source components, and distinguish pre-existing
PIXIE concepts from code created for the event.
