# PIXIE Holdings vault starter

Copy this folder into a new or existing Obsidian vault. Do not replace an existing
`.obsidian` configuration. The structure is additive and works without plugins.

Start in `00 Inbox`, create a source record from `99 Templates`, and link it to a
project map. Keep media in `90 Attachments` under its original filename. Record any
approved move in `30 Decisions` so it can be reversed.

DAW sessions and release assets belong in `50 Productions`; the session, sources,
stems, mixes, masters, captions, artwork, rights, and delivery manifests remain
visibly distinct.
